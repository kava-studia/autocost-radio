# СТУДИЯ РАДИО - project specification

## Идея

СТУДИЯ РАДИО - рекламно-музыкальная сеть для таксистов и других водителей, перевозящих пассажиров.

Водитель включает один из музыкальных каналов на дополнительном телефоне. Система фиксирует события прослушивания, начисляет вознаграждение за валидные минуты и периодически вставляет рекламные сообщения. После рекламной вставки музыка продолжается.

## Регистрация

Для демо не требуются паспортные данные.

Используются:
- локально созданный driver_id
- позывной или внутренний номер водителя

Важно: в production нужно отдельно определить политику персональных данных. User-Agent, IP-адрес, идентификатор устройства и платёжные реквизиты могут считаться персональными данными в зависимости от архитектуры и юрисдикции.

## Музыкальные каналы

1. Coffee Lo-Fi
2. Calm Lo-Fi
3. Midnight Jazz
4. City Hip-Hop
5. Night House
6. City Funk
7. Ambient Drive
8. Retro Synth

В демо звук процедурный и генерируется в браузере.

В production использовать только:
- собственные мастер-файлы
- AI-генерацию с подтверждёнными коммерческими правами
- музыку по лицензии, которая прямо допускает коммерческое использование и нужный способ публичного воспроизведения

Для каждого трека хранить source ledger: источник, дата, лицензия, право коммерческого использования, мастер-файл, автор/генератор.

## Аналитика

Основные события:
- register
- play_start
- pause
- station_switch
- mute_on
- mute_off
- visibility_change
- heartbeat
- ad_start
- ad_end
- session_end

Heartbeat отправляется раз в минуту.

Для production валидную минуту считать только сервером. Клиентский таймер считать интерфейсной подсказкой, а не источником денег.

## Вознаграждения

Ставка должна храниться как конфигурация на сервере.

Текущая демо-ставка 0.03 рубля за минуту оставлена как временное значение из старой версии идеи и не должна считаться утверждённой бизнес-моделью.

Вознаграждение можно конвертировать в:
- деньги
- кофе и еду
- товары партнёров
- шиномонтаж и автосервис
- промокоды и сертификаты

## Реклама

План:
- рекламная вставка каждые 10-15 минут
- музыка приостанавливается
- проигрывается рекламный джингл или нативная интеграция
- музыка автоматически продолжается

В демо используется Speech Synthesis браузера и есть кнопка ручного теста рекламы.

Стартовые рекламодатели и проекты:
- Гастробар на Ясной
- Будем Знакомы
- Кофе Вафли
- Bambinium
- Земли Pro
- СтройЭксперт Pro
- Евгения Travel

## Офлайн-размещение

В автомобиле:
- A4-постер на заднем сиденье
- название СТУДИЯ РАДИО
- QR-код
- краткое объяснение для пассажира
- переход в общий KAVA-хаб

Через хаб пассажир видит проекты сети, партнёров, акции и рекламные интеграции.
